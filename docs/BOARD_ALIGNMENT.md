# Original-question blueprint alignment

The existing mixed-practice planner uses the five published domain targets: Acute Care and Diagnosis 35%, Chronic Care Management 25%, Emergent and Urgent Care 20%, Preventive Care 15%, and Foundations of Care 5%. The version and official source pointers are maintained in `shared/blueprint.js`. This change preserves the existing weights and largest-remainder allocation.

The board catalog includes `alignment`, a version-one audit summary. Its `crosswalkVersion` is `original-question-primary-domain-v1`. Routine catalog responses omit the item crosswalk to avoid repeatedly transferring an unused full inventory. The read-only `boardPractice.alignment()` method returns the full audit for an explicit authenticated audit request. Both projections retain the same current inventory fingerprint, domain counts and limitations; neither uses a stale cache.

In the full audit, each current canonical question appears exactly once with its key, fingerprint, condition/question identity, publisher-authored primary domain and source IDs. The question's own domain determines its count, even when it differs from the condition's browsing domain. Source IDs are scoped by the condition; a Foundations topic remains a study topic rather than an added disease. Questions marked `examScope: comparative-study` remain accessible in the library, grading and sourced cards but are excluded from the U.S. practice pool before this audit is built. Unknown scope values are rejected. The default for unchanged legacy items is U.S. board study, without adding metadata that would unnecessarily change their identities.

`poolFingerprint` hashes the versioned, deterministically sorted crosswalk. A changed canonical question/source fingerprint, domain assignment, source ID or eligible inventory changes this identity. The crosswalk contains no answer keys, rationales, question prose, learner answers or personal progress. The hash documents inventory identity; it does not verify that a medical claim is correct or that the domain assignment was independently adjudicated.

The diagnostic requires the canonical curriculum metadata contract: current status, unique key and fingerprint, one known primary domain, condition/question IDs consistent with the key, and one to eight unique source IDs. The built-in condition and foundation curricula already supply this metadata. A custom adapter accepted by the older practice pool can still fail the new catalog diagnostic if it omits or contradicts these identity/source fields; it must supply the canonical metadata before exposing an auditable catalog. Selection and grading rules are otherwise unchanged.

For each domain, the report gives the target percentage, currently available question count, distinct topic count, raw-bank percentage and difference from the target in percentage points. Empty pools use null percentages rather than inventing a distribution. Distinct topic counts do not measure complete objective coverage. Rounding may make displayed raw-bank percentages sum slightly above or below 100%.

The existing session plans remain authoritative for availability. Their gaps now include `shortfall`, the required count minus the available count. Unfilled allocations are visible and are never silently redistributed into another domain. A small session can round a domain to zero; that rounding does not remove the domain from the blueprint or establish comprehensive coverage. Source expiry or withdrawal can reduce current availability while historical scores remain historical.

This is an audit of original publisher metadata and current inventory. The report explicitly states that complete exam coverage is not established. Topic completeness, item difficulty, medical accuracy and exam readiness have not been evaluated by this diagnostic. These questions are independent educational material, not official ABFM exam items, an official score or a passing prediction. Existing source, clinician-review and commercial-publication boundaries remain unchanged.

Focused validation belongs in the shared validation ledger. The new checks exercise question-level counting, deterministic revision identity, shortages, malformed identities, expiry and output isolation with synthetic curricula. They do not make paid model requests or establish medical correctness.
