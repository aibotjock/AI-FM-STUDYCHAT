# Rebuild scope

Source: the user-supplied Residency-Coach-AI ZIP. Destination: aibotjock/AI-FM-STUDYCHAT, private repository.

This version is an installable responsive web application, not a compiled Expo APK or App Store binary. It serves one personal study workspace from one Node process and stores records in SQLite.

Preserved: navy/gold design direction, coaching, eight simulation concepts, deliberate practice, and six competency domains. Added: adaptive review scheduling, retrieval cards, draft approval, weak-topic context, backup/restore, microphone dictation, and mobile home-screen assets.

Corrected source issues: the COVID-19-labeled scenario describes MMR; the original teach-back exercise did not ask the patient to explain in their own words; visit-based streaks did not measure actual study. Formal-looking milestone predictions have been replaced with clearly labeled learner reflections.

No prior conversations could be reconstructed from the empty conversations.json. No original database or per-device progress was supplied. The uploaded archive and its embedded Git history are not pushed into the new repository; credentials and editor artifacts are excluded.

Validation: 22 automated tests pass, covering scheduling and backend behavior, and all JavaScript syntax and required home-screen assets pass the checks. The browser runtime was unavailable and its download failed, so visual layout and interactive browser QA remain unverified. A real phone, microphone permission, installation flow, and live AI provider also require testing on the deployed app.
